# Task Manager Web Application

A responsive and user-friendly web-based Task Manager designed to help users efficiently create, organize, and track daily tasks. The application provides task filtering, sorting, completion tracking, and real-time productivity statistics with data stored in the browser’s Local Storage.

---

## Features

- Add new tasks  
- Mark tasks as completed or undo completion  
- Delete tasks  
- Filter tasks (All / Pending)  
- Sort tasks (By Date / A–Z)  
- Real-time statistics (Total, Completed, Pending)  
- Completion rate calculation  
- Clear all completed tasks  
- Persistent storage using Local Storage  
- Responsive design  

---

## Technologies Used

- HTML – Page structure  
- CSS – Styling and responsive layout  
- JavaScript – Application logic  
- Browser Local Storage API – Data persistence

## How It Works

1. Users add tasks through the input form.  
2. Tasks are saved in the browser’s Local Storage.  
3. JavaScript dynamically renders tasks on the page.  
4. Users can filter, sort, mark tasks as complete, or delete them.  
5. Statistics update automatically in real time.
